# Project Summary
The Document Management System (DMS) is a self-hosted platform designed to improve collaboration and efficiency in document handling for enterprises. It facilitates secure document upload, viewing, commenting, and organization while effectively managing user permissions. Built with modern technologies such as React, Node.js, Express, and TypeScript, the system leverages PostgreSQL for data storage and utilizes the local filesystem for file management. Key features include user management, document versioning, tagging, sharing capabilities, and comprehensive analytics, making it an ideal solution for organizations seeking to optimize their document workflows.

# Project Module Description
- **Document Management**: Efficiently upload, view, edit, delete, and manage documents.
- **Folder Navigation**: Organize documents into folders for easier access.
- **Comments and History**: Add comments and view the edit history of documents.
- **File Indexing**: Assign unique identifiers and properties to documents.
- **Downloadable Files**: Options to download documents.
- **Desktop App Compatibility**: Open documents in compatible desktop applications.
- **Accessibility Features**: Enhanced usability for various document formats.
- **Authentication System**: JWT-based authentication with access and refresh tokens.
- **Permissions Management**: Manage user access levels for documents.
- **Workflow Management**: Create and manage approval workflows for documents.
- **Audit Logging**: Track actions performed on documents for compliance and security.
- **Version Control**: Maintain document versions for tracking changes.
- **Tagging System**: Organize documents with tags.
- **User Profile Management**: View and edit user profile information.
- **Change Password**: Securely update user passwords.
- **Two-Factor Authentication**: Enhance security with an additional layer.
- **User Management**: Manage user accounts and roles with a departmental structure.
- **Document Sharing System**: Comprehensive sharing interface with configurable permissions.
- **Activity Tracking**: Logs and visualizes document-related activities.
- **Real-Time Dashboard**: Automatically updates to reflect new activities.
- **Branding Customization**: Centralized system for customizing app branding.
- **Database Integration**: Utilizes PostgreSQL for robust data management.
- **Analytics & Dashboard**: Provides insights into document usage and user activity.

# Usage
1. **Install Dependencies**: Run `pnpm install` to install all necessary dependencies.
2. **Build the Project**: Use `pnpm run build` to create a production build.
3. **Run the Application**: Execute `pnpm run dev` to start the development server.
4. **Configure Environment**: Set up a `.env` file with your database credentials and JWT secrets.
5. **Run Migrations**: Execute migration scripts to set up the database schema.
6. **Seed Initial Data**: Seed the database with initial user and tag data.
7. **Access Diagnostic Tools**: Use diagnostic HTML files for troubleshooting issues.
